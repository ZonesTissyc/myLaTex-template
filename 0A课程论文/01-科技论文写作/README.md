# 《科技论文写作》课程论文 LaTeX 模板（2026）

本模板依据用户提供的《科技论文写作》论文专用模板 PDF 制作。红色批注和灰色水印不属于论文正文，未纳入输出。

## 文件

- `techpaper2026.cls`：页面、字体、标题、摘要、图表、公式、引用与参考文献格式。
- `科技论文写作.tex`：可直接编译的示例论文；写作时替换其中内容即可。

## 编译

必须使用 XeLaTeX。在本目录运行：

```bash
latexmk -xelatex 科技论文写作.tex
```

清理辅助文件：

```bash
latexmk -C
```

## 字体

模板优先使用 PDF 指定的宋体、黑体和 Times New Roman：

- 当前环境：优先读取 `/home/ztc/share/Windows系统字体/Fonts/` 中的
  `simsun.ttc`、`simhei.ttf` 和 `times*.ttf`。宋体需要加粗时由 XeLaTeX
  生成适度伪粗体；`simsunb.ttf` 实际是 SimSun-ExtB，并非粗宋体，因此不使用。
- 其他环境：若找不到上述目录，则尝试系统安装的字体；Linux 中文正文优先回退到较轻的 AR PL SungtiL GB。

若学校要求最终文件必须使用微软原字体，请在安装这些字体的机器上编译最终 PDF。

## 使用说明

1. 在 `科技论文写作.tex` 开头填写论文题目、姓名、学号和班级。题目命令的可选参数用于设置较短的页眉标题。
2. 用 `paperabstract` 环境撰写摘要，用 `\paperkeywords{...}` 填写 3～5 个关键词。
3. 使用 `\section`、`\subsection`、`\subsubsection`、`\paragraph` 对应一至四级标题。
4. 图、表和公式使用标准 LaTeX 环境，模板会自动连续编号。
5. 参考文献使用作者—年代制。条目需按“中文在前、外文在后”手工排序，以准确满足原 PDF 的拼音及字母排序要求。

## 根据示例反推的默认值

原 PDF 没有标出精确页边距。本模板按页面比例采用上、下 2.54 cm，左、右 3.17 cm；页脚统一为“第 n 页 共 N 页”。如后续取得 Word 原模板，可再按其页面设置精确校准。
